# Color Picker 🎨

Change the website background color dynamically with one click!

## 📌 Description 
Color Picker is a simple JavaScript project that allows users to modify the website background color randomly or select between predefined colors. Additionally, the text color automatically adjusts to ensure readability.

## 🚀 Features
✅ Changing the background colors via buttons  
✅ Generate random colors  
✅ Automatically adjust text color based on contrast  
✅ Responsive and intuitive interface  
  
## 🛠️ Tecnologies Used
- HTML
- CSS
- JavaScript

## 📦 Installation and Usage

Clone the repository and open the index.html in your browser:  
`git clone https://github.com/khawanlucas/color-flipper.git
cd ColorChanger`  
Or simply access it via your browser.

## 🎯 How to Use
1. Click a button to change the background color.
2. The text color will automatically switch to black or white, depending on the selected color's brightness.
3. The *Random* button generates a dinamically created color.
